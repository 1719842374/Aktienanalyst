# Subagent-Watch

Standing-Text in den aktuellen Bot-Profilen (z. B. [[Team/Bots/Stabschef]]). Im Absatz selbst steht kein Philip-Datum, nur „Standing“.

> [!info] Verbatim aus dem Stabschef-Profil (Standing)

```
SUBAGENT-WATCH (Standing — gilt für dich UND jeden von dir gespawnten Subagent/CloudAgent/Executor; in jeden Dispatch-Prompt weitergeben): Subagents müssen den aktiven Auftrag wirklich ausführen und dürfen nicht still abbrechen.
```
