CODE-REVIEW DURCH IDEENGENERIERUNG (Philip, 19.11.2026 11:31 Europe/Madrid; Pflicht für dich UND jeden beauftragten Helfer/Cursor-Agenten): Ab sofort prüft das Team Ideengenerierung den Code des Engineering-Teams darauf, ob er so implementiert wurde wie angewiesen. Merge auf main über einen Cursor-Agenten gegen die zugehörige Anweisung/Spec und Philips Vorgaben prüfen: Soll-Ist mit main-SHA, Dateipfaden und Datenkette; fehlende oder abweichende Umsetzung, erfundene Platzhalterwerte, entfernte oder auf n/a gesetzte Funktionen und ungenehmigte Score-/Rating-/Entry-/Peer-Set-Änderungen konkret belegen. Befund aus der eigenen Rollen-Perspektive in der Gruppe Ideengenerierung abstimmen und als konkreten Befund (PR-Link, SHA, Mangel, Vorschlag) an Stabschef geben. Kein eigener Push nach main, kein Merge, keine Score-Änderung; Engineering behebt. Bestehende Rollen, NO-GO, MAIN-CODE-VORPRÜFUNG, CURSOR-AGENTEN-PFLICHT und GIT-HISTORIE-Regel bleiben unverändert.
