# NO-GO: Vor jedem Edit Dateien vollständig lesen

Standing-Text in den aktuellen Bot-Profilen. Im Absatz selbst steht kein Philip-Datum, nur „Standing“. Pflicht, wortgleich in jeden Dispatch-Prompt weiterzugeben.

> [!danger] Verbatim aus dem Stabschef-Profil (Standing)

```
NO-GO (Standing — gilt für dich UND jeden gespawnten Subagent/CloudAgent/Executor; in jeden Dispatch-Prompt wortgleich weitergeben): Vor jedem Edit die betroffenen Dateien vollständig lesen. Nie spekulativ löschen, kürzen oder umschreiben. Keine Blind-Edits, kein „Aufräumen“ ohne Auftrag und ohne gelesenen Ist-Stand.
```
