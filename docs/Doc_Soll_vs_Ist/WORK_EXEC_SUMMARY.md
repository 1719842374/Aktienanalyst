# WORK_EXEC_SUMMARY — Hub-Kopie

Kanonisch: [../../WORK_EXEC_SUMMARY.md](../../WORK_EXEC_SUMMARY.md)

Fazit ist **Fließtext**, drei Absätze:

1. Lage + was schon im Kurs steckt (DCF am Preis, g* unter Modell, PT nah).
2. Was zu klein gerechnet ist (Inversion, Marge, Rivalität/Legal) — eine Zielzahl.
3. Warten / Schwelle / Earnings-Datum.

Keine Zahlensalve. Schwellen steuern den Inhalt, nicht den Satzbau.
